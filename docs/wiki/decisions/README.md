## 작성 규칙

- 단순 작업 메모가 아니라 되돌리기 어렵거나 여러 Agent에 영향을 주는 결정을 기록합니다.
- 결정이 바뀌면 기존 문서를 지우지 않고 새 ADR에서 `superseded` 관계를 남깁니다.
- 비용, 공개 게시, 민감 권한, 품질 게이트 완화는 CEO 승인 근거를 기록합니다.
