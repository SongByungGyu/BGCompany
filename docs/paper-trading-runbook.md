# Phase 2-T.1 내부 모의투자 운영 안내

## 안전 경계

- 실행 모드는 `PAPER`만 허용한다.
- `LIVE_TRADING_ENABLED=true` 또는 `TRADING_MODE=LIVE`가 감지되면 실행을 거부한다.
- 외부 주문 권한은 항상 `NONE`이다.
- 체결 장소는 `INTERNAL_VIRTUAL_BROKER`이며 증권사 주문 API를 호출하지 않는다.
- 실제 보유계좌 데이터와 모의계좌 데이터는 서로 다른 Prisma 모델에 저장한다.

## 기본 한도

- 초기 자금: 10,000,000 KRW
- 거래당 계좌 위험: 0.5%
- 종목당 최대 비중: 10%
- 전체 최대 노출: 80%
- 동시 보유: 8종목
- 하루 신규 진입: 3종목
- 슬리피지: 편도 15bp
- 수수료 가정: 편도 0.5bp

수량은 `계좌 위험 한도`, `종목 비중 한도`, `전체 노출 한도`, `가용 현금` 중 가장 작은 값으로 결정한다.

## 화면

BG Company의 `주식` 메뉴에서 `모의투자` 탭을 연다.

1. `모의계좌 시작`을 눌러 초기 계좌를 만든다.
2. 총자산·현금·모의 보유종목·실현/미실현 손익을 확인한다.
3. 주문·체결·거절 신호와 위험 이벤트는 감사 로그에서 확인한다.
4. `일시정지`는 신규 모의 실행을 멈춘다.
5. `긴급 정지`는 `KILLED` 상태로 전환하며 UI에서 다시 켤 수 없다.

## 일일 실행 입력

내부 실행기는 `POST /api/portfolio/paper/run`으로 전일 종가 신호와 당일 OHLC를 받는다. 관리자 세션이 필요하다.

```json
{
  "marketDate": "2026-08-10",
  "observedAt": "2026-08-10T20:10:00Z",
  "usdKrw": 1400,
  "quotes": [
    {
      "symbol": "AAPL",
      "marketDate": "2026-08-10",
      "observedAt": "2026-08-10T20:10:00Z",
      "open": 220,
      "high": 225,
      "low": 218,
      "close": 224
    }
  ],
  "signals": [
    {
      "id": "chart-lab-v3:AAPL:2026-08-07",
      "symbol": "AAPL",
      "name": "Apple",
      "strategy": "trend_breakout",
      "strategyVersion": "chart-lab-v3-forward",
      "signalDate": "2026-08-07",
      "referencePriceUsd": 219,
      "stopPriceUsd": 209,
      "targetPriceUsd": 239,
      "score": 82,
      "reasons": ["close_above_ema200", "breakout_20d", "risk_on"]
    }
  ]
}
```

현재 봉을 이용해 생성한 동일 날짜 신호, 오래된 시세, 비정상 갭, 중복 신호, 한도 초과, 현금 부족은 모두 거절하고 기록한다. 같은 시장 날짜를 다시 호출하면 계좌 상태를 바꾸지 않는다.

## 체결 규칙

- 신호일보다 뒤의 거래일 시가에 진입한다.
- 진입 가격은 `시가 + 슬리피지`다.
- 일봉에서 손절과 목표가가 모두 닿으면 손절을 먼저 적용한다.
- 손절가 아래로 갭 하락하면 손절가가 아니라 시가를 기준으로 체결한다.
- 성공한 일일 실행은 날짜별 Snapshot 하나만 저장한다.

## 아직 연결하지 않은 항목

- KIS 모의계좌 주문 API
- 실계좌 주문·정정·취소 API
- 자동 매수·매도 스케줄러
- 장중 시세와 부분 체결

다음 단계에서는 현재 차트 연구 엔진이 만든 전일 후보를 이 입력 형식으로 정규화하고, KIS 읽기 전용 시세로 일일 OHLC를 확인하는 브리지를 추가한다.
