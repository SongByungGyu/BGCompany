# Naver Blog Operation Guide

## 매일 운영 루틴

1. BG Company 콘텐츠 화면에서 오늘의 브리핑 파이프라인을 확인한다.
2. Hermes 사용량과 실행 제한을 확인한다.
3. 승인 완료 콘텐츠의 네이버 게시 준비 패널을 검토한다.
4. Naver Draft Job을 생성한다.
5. 로컬 PC에서 Naver Draft Agent를 실행한다.
6. 네이버 글쓰기 화면에 입력된 초안을 확인한다.
7. 사용자가 직접 발행한다.

## Local Draft Agent

- 서버가 네이버 로그인 정보를 저장하지 않는다.
- 로컬 브라우저에서만 네이버 세션을 사용한다.
- 기본 원칙은 임시저장 또는 사용자 확인 후 발행이다.

## 장애 대응

- 브라우저가 열리지 않으면 Windows 보안/Playwright 브라우저 설치/프로필 경로를 확인한다.
- `security_check_required`는 네이버 로그인 또는 보안 인증이 필요한 상태다.
- 저장 실패 시 글쓰기 화면에서 수동 저장을 먼저 확인한다.
