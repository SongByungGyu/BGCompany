# Image Prompt Policy

BG Company prepares image prompts for manual image generation only.

## Generated prompt types

- Thumbnail prompt
- Section infographic prompt
- Inline checklist prompt

## Negative prompt baseline

Every image prompt should avoid:

- company logos and trademarks
- copyrighted news photos
- real index numbers unless verified
- buy/sell recommendation text
- profit guarantees or sensational phrases
- impersonation of real publishers

## Current scope

- No image generation is executed automatically.
- No external image API is called.
- The UI only exposes copy-ready prompts for manual use.
