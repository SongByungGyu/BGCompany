# BG Company 2.0 다음 구현 작업

기존 운영을 유지하면서 사업 하나를 끝까지 개발하는 것이 목표다. 아래 작업은 순서대로 연결하며 선행 검증을 통과해야 다음 단계로 진행한다. 현재 상주 실행기는 연결되지 않았다.

| 순서 | 작업 | 완료 기준 | 현재 조건 |
|---|---|---|---|
| 1 | VPS 실제 상태 조사 | Git·이미지·Docker·DB·백업·cron·자원 결과와 확인 불가 항목 분리 | SSH 네트워크 및 등록된 연결 미확보 |
| 2 | 서버 Codex 인증과 사용량 확인 | 개인 PC를 꺼도 서버에서 인증된 실행 가능, 한도 중단 신호 검증 | CLI와 서버 인증·관측 수단 미확인 |
| 3 | Worker와 실행 감독기 | 실행 종류 허용 목록, 격리 작업 공간, 제한된 권한, timeout·heartbeat 취소·실제 프로세스 종료 검증 | 큐 인터페이스 구현 완료, 감독기 미구현 |
| 4 | Research Agent | 실제 출처와 수집 시각을 붙인 사업 후보 10개; 수요·경쟁·구현 비용·수익화 근거 비교 | 실행기 연결 후 |
| 5 | Planner | 후보 1개 선정 이유, 범위, 데이터 모델, API, 성공 지표, 비용 상한, 작업 분해 | 근거가 있는 후보 필요 |
| 6 | Builder와 QA | GPT-6 Sol 사용 가능 여부 확인, 별도 Git 브랜치에 코드 개발, 빌드·테스트·보안 검사, 커밋과 증거 기록 | 격리 실행기 필요 |
| 7 | 시험 배포 | 운영 서비스와 분리된 Docker 구성, 제한된 접근, 상태 검사와 롤백 검증 | 서버 조사와 시험 환경 접근 필요 |
| 8 | Growth | 실제 방문·사용량 수집, 테스트 이벤트 구분, 결제·정산 웹훅 서명 검증과 중복 방지 | 결제 활성화는 승인 전 보류 |
| 9 | 개선 사이클 | 지표 기준과 관측 기간을 고정한 변경, 전후 지표·실제 AI 비용 기록, 효과 미확인 시 되돌리기 | 실제 서비스 지표 필요 |

우선순위는 Hostinger VPS다. 측정된 여유 자원이 부족한 경우에만 GTX 1070 Ti 작업 서버를 추가한다. 로컬 LLM, GPU 업그레이드, 새 유료 서비스와 도메인 구매는 필수 조건으로 두지 않는다.

최종 공개, 결제 활성화, 고위험 권한 변경은 구체적인 변경 내용과 검증·롤백 증거가 준비된 뒤 승인받는다. 일상적인 조사, 개발 브랜치 작업, 격리 테스트와 실패 복구는 확보된 권한 안에서 별도 중간 확인 없이 진행한다.
